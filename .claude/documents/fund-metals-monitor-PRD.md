## 1. 产品概述

### 1.1 产品名称

暂定名：**「流光」** — 基金 & 贵金属实时监控平台

### 1.2 产品简介

「流光」是一款面向年轻投资者的基金与贵金属实时行情监控工具。用户可以自由添加持仓基金及买入金额，实时查看净值、估值、收益，同时监控黄金、白银、铂金等贵金属的国际价格与人民币换算价格，并通过自定义预警在价格触及目标位时第一时间收到系统通知。

### 1.3 核心价值主张

- **实时感知**：秒级/分钟级刷新基金估值与贵金属价格
- **持仓管理**：记录每只基金买入金额，直观呈现每日浮盈/浮亏
- **预警提醒**：自定义目标价，首次触达时推送系统通知
- **酷炫体验**：暗色主调 + 霓虹渐变 + 数据动效，贴合年轻审美

## 2. 目标用户与定位

### 2.1 核心用户画像

| 维度     | 描述                                                   |
| -------- | ------------------------------------------------------ |
| 年龄     | 18 ~ 35 岁                                             |
| 身份     | 在校大学生、职场新人、年轻白领                         |
| 投资经验 | 初级～中级，持有公募基金、有贵金属投资意向             |
| 设备习惯 | 主力使用手机（H5），偶尔使用 PC 大屏查看详情           |
| 核心诉求 | 想快速了解自己的基金和贵金属是否在赚钱，不想翻多个 APP |

### 2.2 设计调性

- **视觉风格**：科技感、暗色系（Dark Mode 为主）、霓虹高亮色、流动渐变
- **信息密度**：数据丰富但层次清晰，不堆砌
- **情感化设计**：数字变化有动效，涨跌有色彩呼应（涨绿跌红 或 涨红跌绿，跟随用户偏好设置）
- **参考风格**：Bloomberg Terminal 年轻化版本 + Crypto 行情 APP 的视觉语言

### 3.1 技术栈选型

| 层级       | 技术选型                                                                             | 备注                                                                                                  |

| 通知 API   | Web Notifications API（Notification）                                                | 系统级推送通知                                                                                        |

## 4. 功能模块详述

### 4.1 基金监控模块

#### 4.1.1 基金添加与管理

**功能描述：** 用户可通过搜索或手动输入方式，将自己持有的基金添加到监控列表，并记录持仓信息。

**详细需求：**

| 编号  | 需求点             | 优先级 | 说明                                             |
| ----- | ------------------ | ------ | ------------------------------------------------ |
| F-001 | 按基金名称搜索添加 | P0     | 输入关键词，实时返回匹配基金列表                 |
| F-002 | 按基金代码搜索添加 | P0     | 输入 6 位数字代码精确匹配                        |
| F-003 | 填写持仓份额/金额  | P0     | 支持输入「买入金额（元）」或「持有份额」两种模式 |
| F-004 | 填写买入成本净值   | P1     | 可选填，用于计算持仓盈亏                         |
| F-005 | 编辑已添加基金信息 | P0     | 修改持仓金额、份额、备注                         |
| F-006 | 删除基金           | P0     | 带二次确认，防误删                               |
| F-007 | 基金排序/分组      | P2     | 支持拖拽排序，支持创建分组（如「稳健」「成长」） |
| F-008 | 导入/导出持仓数据  | P2     | 支持 JSON 格式导入导出，便于备份迁移             |

**搜索流程：**

```
用户输入关键词（≥2字）
    ↓
防抖 300ms 后调用基金搜索 API
    ↓
下拉列表展示：基金代码、基金名称、基金类型、最新净值
    ↓
用户选择 → 弹出添加弹窗 → 填写持仓信息 → 确认保存
    ↓
写入 IndexedDB，更新 Zustand store
```

#### 4.1.2 基金数据展示

**基金卡片（列表视图）展示字段：**

| 字段            | 说明                                  | 数据来源                    |
| --------------- | ------------------------------------- | --------------------------- |
| 基金代码        | 6 位数字代码                          | 本地存储                    |
| 基金名称        | 完整名称（可截断显示）                | API                         |
| 基金类型        | 股票型/混合型/债券型/货币型/指数型    | API                         |
| 最新净值（NAV） | 最近一个交易日的单位净值              | API（每日更新）             |
| 净值日期        | 净值对应的交易日期                    | API                         |
| 实时估值        | 盘中根据持仓股票实时估算的单位净值    | API（交易时段 ~15min 刷新） |
| 估值涨跌幅      | 相较上一交易日净值的百分比变化        | 计算                        |
| 持仓金额        | 用户填入的买入金额（元）              | 本地存储                    |
| 当日实时收益    | 持仓金额 × 估值涨跌幅（元）           | 实时计算                    |
| 当日实时收益率  | 估值涨跌幅（% 展示）                  | 实时计算                    |
| 累计收益        | （当前净值 - 买入成本净值）× 持有份额 | 计算（需填成本净值）        |
| 累计收益率      | （当前净值 / 买入成本净值 - 1）× 100% | 计算                        |

**基金详情页展示字段：**

除卡片字段外，还包括：

| 字段           | 说明                                                               |
| -------------- | ------------------------------------------------------------------ |
| 基金经理       | 姓名、任职年限                                                     |
| 基金规模       | 最新披露规模（亿元）                                               |
| 成立日期       | 基金成立时间                                                       |
| 历史净值走势图 | 折线/面积图，支持切换：近1月、近3月、近6月、近1年、近3年、成立以来 |
| 近期净值列表   | 展示最近 20 条历史净值记录                                         |
| 收益率对比     | 基金本身 vs 同类平均 vs 业绩比较基准（三条线）                     |
| 资产配置       | 饼图（股票/债券/现金等占比）                                       |
| 分红记录       | 历史分红记录列表                                                   |
| 手续费信息     | 申购费、赎回费、管理费、托管费                                     |

### 4.3 价格预警通知模块

#### 4.3.1 功能描述

用户可以为每个贵金属品种（及基金净值）设置目标价格（预期价格），当**实时价格首次小于等于**该目标价时，系统通过 **Web Notifications API** 向用户的操作系统通知中心推送通知，且该预警仅触发一次（防止反复骚扰）。

#### 4.3.2 预警规则详述

| 编号  | 规则         | 说明                                                                 |
| ----- | ------------ | -------------------------------------------------------------------- |
| A-001 | 触发条件     | 实时价格 ≤ 用户设置的目标价格                                        |
| A-002 | 单次触发     | 每条预警规则在当次设置有效期内只触发一次通知                         |
| A-003 | 触发后状态   | 预警变为"已触发"状态，可选择重置或删除                               |
| A-004 | 权限请求     | 首次使用预警功能时，向用户申请浏览器通知权限                         |
| A-005 | 权限拒绝降级 | 若权限被拒，应用内展示悬浮 Banner 提示                               |
| A-006 | 页面关闭处理 | 预警检测依赖页面打开状态；若页面关闭则无法触发，需在 UI 明确告知用户 |
| A-007 | 多条预警     | 同一品种可设置多条预警（不同目标价）                                 |
| A-008 | 基金预警     | 支持对基金净值设置目标价预警（同规则）                               |

#### 4.3.3 预警通知内容格式

```
通知标题：「流光」价格预警触发 🔔
通知正文：黄金现价 ¥642.5/g，已达到您设定的目标价 ¥650/g
通知图标：产品 Logo
点击行为：跳转至对应贵金属/基金详情页
```

#### 4.3.4 预警管理 UI

- 预警列表页：展示所有已设置的预警规则，包含品种、目标价、设置时间、状态（监控中/已触发）
- 每条预警支持：编辑目标价、重置状态（重新激活）、删除
- 未触发预警用高亮色标注，已触发的置灰

#### 4.3.5 通知权限引导流程

```
用户点击"添加预警"
    ↓
检查 Notification.permission
    ├─ "granted"  → 直接进入设置界面
    ├─ "default"  → 弹出引导说明 Modal → 用户确认 → requestPermission()
    └─ "denied"   → 提示用户手动在浏览器设置中开启，展示操作截图引导
```

**表二：分组信息（`fund_groups`）**

| 字段名    | 类型           | 说明       |
| --------- | -------------- | ---------- |

**表三：价格预警规则（`price_alerts`）**

#### 4.4.3 数据备份与恢复

- 支持导出全量数据为 `.json` 文件（包含基金持仓、分组、预警、设置）
- 支持导入 `.json` 文件恢复数据（含版本兼容性校验）
- 每次导入前提示用户当前数据将被覆盖，需二次确认

> **主题实现方式：** shadcn/ui 默认使用 CSS Variables 管理所有颜色 Token（`--background`、`--foreground`、`--primary` 等），在 `globals.css` 中分别定义 `:root`（亮色）和 `.dark`（暗色）两套变量，Tailwind 的 `darkMode: 'class'` 策略通过在 `<html>` 元素切换 `dark` class 实现主题切换，无需任何运行时主题引擎。

## 6. 数据源与接口规划

### 6.1 基金数据

| 数据类型     | 推荐数据源                          | 接口说明                                    |
| ------------ | ----------------------------------- | ------------------------------------------- |
| 基金搜索     | 天天基金网 / 蛋卷基金 API（非官方） | 按名称/代码搜索                             |
| 基金实时估值 | 天天基金估值接口                    | `http://fundgz.1234567.com.cn/js/{code}.js` |
| 历史净值     | 天天基金历史净值接口                | 分页获取 OHLC 净值                          |
| 基金基本信息 | 天天基金详情接口                    | 规模、经理、费率等                          |

> **注意：** 上述接口均为非官方公开接口，存在被封风险，建议在后端做代理转发以隐藏来源并做缓存，避免直接在前端裸调。若有商业化意图，需接入官方授权数据（如聚合数据、东方财富开放平台）。

### 6.2 贵金属数据

| 数据类型            | 推荐数据源                                           | 说明                                  |
| ------------------- | ---------------------------------------------------- | ------------------------------------- |
| 伦敦金现货价格      | **GoldAPI.io** 或 **Metals-API**                     | 提供 XAU/XAG/XPT 实时报价，有免费额度 |
| 备用数据源          | **Alpha Vantage**（PHYSICAL_CURRENCY_EXCHANGE_RATE） | 免费 API，每分钟限频                  |
| 实时汇率（USD/CNY） | **ExchangeRate-API** 或 **Open Exchange Rates**      | 有每日免费额度，汇率刷新频率约5分钟   |

**推荐方案：** 前端不直接调用第三方 API（跨域 + 密钥安全问题），通过自建轻量 BFF（Backend for Frontend）代理，或使用 Cloudflare Workers / Vercel Edge Functions 做中间层转发。

### 6.3 接口设计建议（BFF 层）

```
GET /api/metals/price?symbols=XAU,XAG,XPT
返回：各品种当前价格（USD）、开盘价、昨收、今高今低

GET /api/metals/history?symbol=XAU&range=1W
返回：历史 OHLC 数组

GET /api/exchange-rate?from=USD&to=CNY
返回：当前汇率、更新时间

GET /api/funds/search?keyword=xxx
返回：基金搜索结果列表

GET /api/funds/estimate?code=xxx
返回：实时估值、估值涨跌幅

GET /api/funds/nav?code=xxx&page=1&size=20
返回：历史净值分页列表
```

## 8. 非功能性需求

### 8.1 性能要求

| 指标                | 目标值                          |
| ------------------- | ------------------------------- |
| 首屏加载时间（FCP） | ≤ 2.0s（4G 网络）               |
| 最大内容绘制（LCP） | ≤ 3.0s                          |
| 数据刷新延迟        | ≤ 500ms（从发出请求到 UI 更新） |
| 图表渲染帧率        | ≥ 60fps（桌面端）               |
| IndexedDB 读写      | ≤ 50ms（常规操作）              |

### 8.2 可用性要求

- 支持离线浏览（展示最后一次缓存的数据，明确标注数据时间戳）
- API 请求失败时展示友好错误状态，提供重试按钮
- 无数据状态提供引导性空态页面（添加基金/贵金属）

### 8.3 兼容性要求

| 浏览器/平台    | 支持版本                   |
| -------------- | -------------------------- |
| Chrome         | ≥ 90                       |
| Safari（iOS）  | ≥ 14                       |
| Edge           | ≥ 90                       |
| Firefox        | ≥ 88                       |
| 微信内置浏览器 | 最新版本（不支持系统通知） |

> Web Notifications API 在微信内置浏览器中不可用，此场景降级为应用内 Banner 提示。

### 8.4 安全要求

- API 密钥（第三方数据源）严禁暴露在前端代码中，统一通过 BFF 代理
- IndexedDB 数据无需加密（均为行情数据，无敏感信息）
- 无需用户账号体系，全量本地化存储

### 8.5 无障碍性（A11y）

- 涨跌状态除颜色外增加图标辅助（▲ / ▼），不依赖颜色传达信息
- 图表提供数据表格备用视图（可切换）
- 所有交互元素有 `aria-label`

## 11. 风险与注意事项

| 风险                    | 等级 | 应对策略                                                        |
| ----------------------- | ---- | --------------------------------------------------------------- |
| 非官方基金 API 失效     | 高   | 封装适配器层，便于快速切换数据源；提前评估接入东方财富官方授权  |
| 贵金属 API 免费额度耗尽 | 中   | 引入请求缓存（Redis / Edge KV），减少重复调用；设置合理轮询间隔 |
| 浏览器通知权限被拒      | 中   | 提供应用内 Banner 降级方案，不强依赖系统通知                    |
| CORS 跨域问题           | 高   | 所有第三方 API 通过 BFF 代理，前端统一调用自有域名接口          |
| IndexedDB 数据丢失      | 低   | 引导用户定期导出备份；清除浏览器数据前明确提示                  |
| 移动端微信环境限制      | 中   | 微信内禁用系统通知功能，明确在 UI 提示；其他功能正常使用        |

### 12.3 换算公式

```
人民币克价（CNY/g）= 美元盎司价（USD/oz）÷ 31.1035 × USD/CNY 汇率

当日浮盈（元）= 持仓金额 × 当日估值涨跌幅（%）/ 100

累计收益（元）= （当前净值 - 买入成本净值）× 持有份额
累计收益率（%）= （当前净值 ÷ 买入成本净值 - 1）× 100

持仓份额（按金额录入时）= 买入金额 ÷ 买入成本净值
```
