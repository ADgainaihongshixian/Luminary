## 1. 产品概述

### 1.1 产品名称

**「流光」** — 基金 & 贵金属实时监控平台

### 1.2 产品简介

「流光」是一款面向年轻投资者的基金与贵金属实时行情监控工具。用户可以自由添加持仓基金及买入金额，实时查看净值、估值、收益，同时监控黄金、白银、铂金等贵金属的国际价格与人民币换算价格，并通过自定义预警在价格触及目标位时第一时间收到系统通知。

### 1.3 核心价值主张

- **实时感知**：秒级/分钟级刷新基金估值与贵金属价格
- **持仓管理**：记录每只基金买入金额，直观呈现每日浮盈/浮亏
- **预警提醒**：自定义目标价，首次触达时推送系统通知
- **酷炫体验**：暗色主调 + 霓虹渐变 + 数据动效，贴合年轻审美

## 2. 目标用户与定位

### 2.1 核心用户画像

| 维度     | 描述                                                   |
| -------- | ------------------------------------------------------ |
| 年龄     | 18 ~ 35 岁                                             |
| 身份     | 在校大学生、职场新人、年轻白领                         |
| 投资经验 | 初级～中级，持有公募基金、有贵金属投资意向             |
| 设备习惯 | 主力使用手机（H5），偶尔使用 PC 大屏查看详情           |
| 核心诉求 | 想快速了解自己的基金和贵金属是否在赚钱，不想翻多个 APP |

### 2.2 设计调性

- **视觉风格**：科技感、暗色系（Dark Mode 为主）、霓虹高亮色、流动渐变
- **信息密度**：数据丰富但层次清晰，不堆砌
- **情感化设计**：数字变化有动效，涨跌有色彩呼应（涨绿跌红 或 涨红跌绿，跟随用户偏好设置）
- **参考风格**：Bloomberg Terminal 年轻化版本 + Crypto 行情 APP 的视觉语言

**搜索流程：**

```
用户输入关键词（≥2字）
    ↓
防抖 300ms 后调用基金搜索 API
    ↓
下拉列表展示：基金代码、基金名称、基金类型、最新净值
    ↓
用户选择 → 弹出添加弹窗 → 填写持仓信息 → 确认保存
    ↓
写入 IndexedDB，更新 Zustand store
```

### 4.3 价格预警通知模块

#### 4.3.1 功能描述

用户可以为每个贵金属品种（及基金净值）设置目标价格（预期价格），当**实时价格首次小于等于**该目标价时，系统通过 **Web Notifications API** 向用户的操作系统通知中心推送通知，且该预警仅触发一次（防止反复骚扰）。

#### 4.3.2 预警规则详述

| 编号  | 规则         | 说明                                                                 | 状态      |
| ----- | ------------ | -------------------------------------------------------------------- | --------- |
| A-001 | 触发条件     | 实时价格 ≤ 用户设置的目标价格                                        | ✅ 已实现 |
| A-002 | 单次触发     | 每条预警规则在当次设置有效期内只触发一次通知                         | ✅ 已实现 |
| A-003 | 触发后状态   | 预警变为"已触发"状态，可选择重置或删除                               | ✅ 已实现 |
| A-004 | 权限请求     | 首次使用预警功能时，向用户申请浏览器通知权限                         | ✅ 已实现 |
| A-005 | 权限拒绝降级 | 若权限被拒，应用内展示悬浮 Banner 提示                               | ✅ 已实现 |
| A-006 | 页面关闭处理 | 预警检测依赖页面打开状态；若页面关闭则无法触发，需在 UI 明确告知用户 | ✅ 已实现 |
| A-007 | 多条预警     | 同一品种可设置多条预警（不同目标价）                                 | ✅ 已实现 |
| A-008 | 基金预警     | 支持对基金净值设置目标价预警（同规则）                               | ✅ 已实现 |

#### 4.3.3 预警通知内容格式

```
通知标题：「流光」价格预警触发 🔔
通知正文：黄金现价 ¥642.5/g，已达到您设定的目标价 ¥650/g
通知图标：产品 Logo
点击行为：跳转至对应贵金属/基金详情页
```

#### 4.3.4 预警管理 UI

- 预警列表页：展示所有已设置的预警规则，分为"监控中"和"已触发"两组
- 每条预警支持：编辑目标价、重置状态（重新激活）、删除
- 未触发预警用高亮色标注，已触发的置灰

#### 4.3.5 通知权限引导流程

```
用户点击"添加预警"
    ↓
检查 Notification.permission
├─ "granted"  → 直接进入设置界面
├─ "default"  → 弹出引导说明 Modal → 用户确认 → requestPermission()
└─ "denied"   → 提示用户手动在浏览器设置中开启，展示操作截图引导
```

#### 4.3.6 预警检测机制

| 资产类型 | 检测频率   | 说明                       |
| -------- | ---------- | -------------------------- |
| 贵金属   | 30 秒/次   | 跟随贵金属实时价格刷新频率 |
| 基金     | 15 分钟/次 | 跟随基金估值刷新频率       |

### 6.2 贵金属数据

| 数据类型            | 数据源                                    | 说明                    | 状态      |
| ------------------- | ----------------------------------------- | ----------------------- | --------- |
| 伦敦金银实时价格    | **新浪财经** `hq.sinajs.cn`               | 国内直连 ~350ms，CNY/克 | ✅ 已实现 |
| 铂金实时价格        | **Gold-API** `api.gold-api.com`           | 海外兜底                | ✅ 已实现 |

**数据源优先级策略：**

- 金银实时价格：新浪财经（国内优先，CNY/克 → USD/盎司 换算）
- 铂金实时价格：Gold-API（海外兜底）
- 历史数据：Twelve Data API（需 API Key）
- 汇率：Open Exchange Rates（免费）

### 6.3 BFF 接口设计

**实际实现的 API 端点：**

```
GET /api/funds/search?keyword=xxx
返回：基金搜索结果列表
缓存：5 分钟

GET /api/funds/estimate?code=xxx
返回：实时估值、估值涨跌幅
缓存：1 分钟

GET /api/funds/nav?code=xxx&page=1&size=20
返回：历史净值分页列表
缓存：5 分钟

GET /api/metals/price?symbols=XAU,XAG,XPT
返回：各品种当前价格（USD）、开盘价、昨收、今高今低
缓存：30 秒

GET /api/metals/history?symbol=XAU&range=1W
返回：历史 OHLC 数组
缓存：5 分钟

GET /api/exchange-rate?from=USD&to=CNY
返回：当前汇率、更新时间
缓存：5 分钟
```

## 11. 风险与注意事项

| 风险                    | 等级 | 应对策略                                                     | 状态      |
| ----------------------- | ---- | ------------------------------------------------------------ | --------- |
| 非官方基金 API 失效     | 高   | 封装适配器层，便于快速切换数据源；BFF 代理隐藏来源           | ✅ 已实现 |
| 贵金属 API 免费额度耗尽 | 中   | 引入请求缓存（BFF 内存缓存），减少重复调用；设置合理轮询间隔 | ✅ 已实现 |
| 浏览器通知权限被拒      | 中   | 提供应用内 Banner 降级方案，不强依赖系统通知                 | ✅ 已实现 |
| CORS 跨域问题           | 高   | 所有第三方 API 通过 BFF 代理，前端统一调用自有域名接口       | ✅ 已实现 |
| IndexedDB 数据丢失      | 低   | 引导用户定期导出备份；清除浏览器数据前明确提示               | ✅ 已实现 |
| 移动端微信环境限制      | 中   | 微信内禁用系统通知功能，明确在 UI 提示；其他功能正常使用     | ✅ 已实现 |
| 新浪财经接口变更        | 中   | 封装独立适配器（sina-finance.ts），便于快速切换              | ✅ 已实现 |

### 12.3 换算公式

```
人民币克价（CNY/g）= 美元盎司价（USD/oz）÷ 31.1035 × USD/CNY 汇率

当日浮盈（元）= 持仓金额 × 当日估值涨跌幅（%）/ 100

累计收益（元）= （当前净值 - 买入成本净值）× 持有份额
累计收益率（%）= （当前净值 ÷ 买入成本净值 - 1）× 100

持仓份额（按金额录入时）= 买入金额 ÷ 买入成本净值
```
